1. 개요
1) 아이디어 주제
- 멀티모달 라이프로그 감정 분석 기반 맞춤형 LLM 케어 및 모니터링 시스템
2) 개발 목표
- 스마트워치·체성분계를 통해 자동 수집되는 멀티모달 라이프로그 분석을 통해
기존 수동 감정 기록의 번거로움 개선
- 시계열 데이터 기반의 감정 변화 패턴 및 정서적 이상 징후의 선제적 조기 판별
- 데이터 기반 위험도 산출에 따른 맞춤형 LLM 인터랙션 및 개인화 케어 콘텐츠
제공
3) 개발 내용
- 웨어러블 기기(스마트워치)를 통한 시계열 생체 활동 데이터 및 대화, 설문 텍스
트 데이터 실시간 수집 및 전처리
- 수집된 멀티모달 데이터를 융합 분석하여 감정 상태 추이 측정 및 우울, 스트레
스 고위험 단계 자동 분류
- 분석된 위험도 단계에 맞춘 페르소나 기반 LLM 공감 대화 수행 및 개인 맞춤형
정서 케어 콘텐츠 추천

4. 모델 생성 및 학습
다변량 시계열 라이프로그의 비정상 패턴 조기 탐지 및 9개 감정
모델링 목표
/3단계 위험도 다중 클래스 분류 정확도 확보
- LSTM Autoencoder (비지도 시계열 이상 감지) + LightGBM
학습 모델
Classifier (지도 정서 위험도 분류)
- PMData 의 정상 패턴 시퀀스로 LSTM Autoencoder 를 학습시
켜 재구성 오차 기반 anomaly_score 를 추출한 뒤, 이를
GLOBEM 의 14일 집계 라이프로그 피처 및 BDI-II 우울 척도
라벨과 결합하여 LightGBM 2단계(Two-Stage) Ensemble 지도학
습을 수행
학습 방법 - EMOTIONS 9개 클래스 중 CRISIS/DESPAIR 등 고위험 클래스는
발생 빈도가 낮아 SMOTE(Synthetic Minority Over-sampling) 또
는 class_weight 조정을 통해 소수 클래스 학습 편향을 보정함
- 동일 사용자의 시계열 데이터가 Train/Test에 동시 포함되지 않
도록 사용자(user_id) 단위 Group K-Fold Cross-Validation을 적
용함
입력 피처 수집 후 추론을 거쳐 감정 코드(emotion_id), 감정
모델 예측 결과 점수(emotion_score), 위험도(risk_level), 위험 점수(risk_score),
Action 플래그(system_action) 동시 산출
5. 검증
1. Cross-Validation(K-Fold) 기반 정밀도(Precision), 재현율(Recall),
F1-Score 산출
2. 실제 생체 이상 파형 데이터 주입을 통한 고위험군 알림 트리
분석 검증 방안
거 응답 속도 및 임계치 성능 검증
사용자 단위 Group K-Fold 기반 검증으로 개인별 패턴 과적합
(Data Leakage) 여부 점검
