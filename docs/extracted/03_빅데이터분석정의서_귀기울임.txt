1. 개요



 1) 아이디어 주제 

멀티모달 라이프로그 감정 분석 기반 맞춤형 LLM 케어 및 모니터링 시스템

 2) 개발 목표

스마트워치·체성분계를 통해 자동 수집되는 멀티모달 라이프로그 분석을 통해 기존 수동 감정 기록의 번거로움 개선

시계열 데이터 기반의 감정 변화 패턴 및 정서적 이상 징후의 선제적 조기 판별

데이터 기반 위험도 산출에 따른 맞춤형 LLM 인터랙션 및 개인화 케어 콘텐츠 제공

 3) 개발 내용

웨어러블 기기(스마트워치)를 통한 시계열 생체 활동 데이터 및 대화, 설문 텍스트 데이터 실시간 수집 및 전처리

수집된 멀티모달 데이터를 융합 분석하여 감정 상태 추이 측정 및 우울, 스트레스 고위험 단계 자동 분류

분석된 위험도 단계에 맞춘 페르소나 기반 LLM 공감 대화 수행 및 개인 맞춤형 정서 케어 콘텐츠 추천

2. 기능별 빅데이터 분석 명세서 



기능명

라이프로그 기반 시계열 이상 감지 및 정서 위험도 분석

데이터 준비

데이터 정의

스마트폰/웨어러블 기기(Health Connect API)로 수집되는 걸음수(steps), 이동거리(distance), 소모칼로리(calories), 수면 데이터(총수면시간·깊은수면·얕은수면·REM수면·각성시간·입면시간·수면효율), 심박수(heart_rate)·심박변이도(HRV) 시계열 데이터, 체성분계 연동 데이터(체중·체지방·근육량·골격근량·기초대사량), 및 대화/설문 텍스트 메타데이터. 심박수·HRV는 자율신경계 반응과 스트레스·정서 상태 간 상관관계가 선행연구(WESAD 등)에서 보고된 지표로, 1차 모델 학습 데이터셋부터 포함한다.

2. 전처리

전처리 과정

이상치 정제 및 결측치 보간: 센서 신호 튀어짐 현상(Noise) 정제, 시계열 결측 데이터 선형 보간 및 이월 보간(Forward Fill) 적용

개인별 스케일링: 사용자별 과거 14일 평소 활동/생체 수치 기준 Min-Max Scaling 정규화

Data Fusion: 정제된 생체 시계열 파형 피처와 대화 NLP 메타데이터를 하나의 통합 피처 Vector로 변환 (개인식별정보 PII [MASK] 전처리 완료 텍스트 기준)

시퀀스 윈도우 구성: 개인별 정규화된 일별 피처를 최근 N일(예: 7일) 단위 슬라이딩 윈도우로 묶어 LSTM 입력용 시퀀스 텐서로 변환

전처리 데이터

AI 스코어링 모델 입력용 정형 시계열 피처 매트릭스(N X M 차원 Vector)

3. 데이터 분석

데이터 분석 목표

1인 가구 사용자가 인지하지 못한 행동/생체 이상 패턴과 부정적 정서 상태를 정량 스코어화하여 조기에 이상 징후를 발견하고 예방

데이터 분석 시나리오

1단계 (LSTM Autoencoder): 평소 정상 패턴의 생체 시계열 시퀀스(수면, 활동량, 심박수 등)를 인코딩-디코딩하도록 비지도 학습시킨 후, 신규 입력 데이터와의 재구성 오차(Reconstruction Error)를 기반으로 이상 행동 변동(활동량 급감, 수면 불규칙 등)을 선제 감지하여 anomaly_score를 산출함.

2단계 (LightGBM): 라이프로그 이상 징후 벡터(anomaly_score)와 챗봇 대화 텍스트 메타데이터를 결합해 종합 risk_score 및 9개 감정 코드(EMOTIONS)를 최종 추론·산출함.

위험도 매핑 및 액션: 추론 스코어와 감정 코드에 따라 3단계 위험도(NORMAL / CAUTION / CRITICAL)를 판정함. ANGER(분노) 감정은 스코어 70 이상 시 CRITICAL 단계로 동적 분기하며, CRISIS(위기) 감정은 즉시 CRITICAL 확정 및 system_action(비상 전화 연결 UI 노출)을 트리거함.

4. 모델 생성 및 학습

모델링 목표

다변량 시계열 라이프로그의 비정상 패턴 조기 탐지 및 9개 감정/3단계 위험도 다중 클래스 분류 정확도 확보

학습 모델

LSTM Autoencoder (비지도 시계열 이상 감지) + LightGBM Classifier (지도 정서 위험도 분류)

학습 방법

공공 라이프로그 오픈 데이터(PMData 등) 및 우울 검사(BDI-II) 라벨 기반 학습. 정상 패턴 시퀀스로 LSTM Autoencoder를 학습시켜 재구성 오차 기반 anomaly_score를 추출한 뒤, 이를 LightGBM 입력 피처로 결합하여 2단계(Two-Stage) Ensemble 지도학습 수행

EMOTIONS 9개 클래스 중 CRISIS/DESPAIR 등 고위험 클래스는 발생 빈도가 낮아 SMOTE(Synthetic Minority Over-sampling) 또는 class_weight 조정을 통해 소수 클래스 학습 편향을 보정함

동일 사용자의 시계열 데이터가 Train/Test에 동시 포함되지 않도록 사용자(user_id) 단위 Group K-Fold Cross-Validation을 적용함

모델 예측 결과

입력 피처 수집 후 추론을 거쳐 감정 코드(emotion_id), 감정 점수(emotion_score), 위험도(risk_level), 위험 점수(risk_score), Action 플래그(system_action) 동시 산출

5. 검증

분석 검증 방안

1. Cross-Validation(K-Fold) 기반 정밀도(Precision), 재현율(Recall), F1-Score 산출

2. 실제 생체 이상 파형 데이터 주입을 통한 고위험군 알림 트리거 응답 속도 및 임계치 성능 검증

사용자 단위 Group K-Fold 기반 검증으로 개인별 패턴 과적합(Data Leakage) 여부 점검

분석 평가 결과

이상 감지 및 정서 위험도 분류 정확도(Accuracy≥85%

F1-Score≥0.80 달성

고위험 상태 감지 시 비상 액션 트리거 지연 시간 3초 이내 검증 완수

2. 전처리

전처리 과정

1. 전화번호, 이름 등 PII 항목 [MASK] 토큰 마스킹

2. 특수문자 및 공백 정제

3. 한국어 LM 토크나이저 서브워드 분할

4. N개 턴 대화 맥락 결합

3. 데이터 분석

데이터 분석 목표

단순 키워드 매칭을 넘어 사용자의 대화 맥락 전체를 분석함으로써 실제 위기 상황(자살/자해 위험, 고위험 정서 상태)을 실시간으로 정확히 탐지

데이터 분석 시나리오

사용자가 챗봇에 입력한 대화 텍스트가 AI 분석 서버로 실시간 스트리밍

사전 학습된 위기 탐지 NLP 모델을 통해 대화의 위기 심각도 카테고리 분류

자해/극단선택 위기 단어 탐지 시 감정 코드를 CRISIS로 즉시 지정하고, 이전 라이프로그 점수와 무관하게 risk_level = CRITICAL, system_action = EMERGENCY 확정

4. 모델 생성 및 학습

모델링 목표

KcBERT / RoBERTa-Large 기반 한국어 위기 분류 모델

학습 방법

Cross-Entropy Loss 기반 지도 학습 및 고위험 클래스 가중치 조정을 통한 미감지 최소화 학습
