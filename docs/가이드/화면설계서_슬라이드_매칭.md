기존 슬라이드를 복제해 붙입니다. 레이아웃·서식·이미지가 그대로 따라오고,

## 화면을 직접 보면서 작업하려면

세 가지 방법이 있고, 목적에 따라 다릅니다.

### 1. 시안만 보면 될 때 — 브라우저 (가장 빠름)

에뮬레이터도 서버도 필요 없습니다. **화면설계서에 들어갈 그림은 이 시안입니다.**

```powershell
start docs\design\MAIN_REPORT_01.png
```

원본 HTML 을 열면 확대해도 안 깨집니다.

```powershell
start docs\design\src\MAIN_REPORT_01.html
```

### 2. 실제 앱 화면을 볼 때 — 원하는 화면으로 바로 띄우기

#### 먼저 에뮬레이터를 켭니다

이 PC 에는 **`lisn` 이라는 에뮬레이터가 이미 만들어져 있습니다.**

```powershell
flutter emulators
```

```powershell
flutter emulators --launch lisn
```

40초~1분쯤 걸립니다. 뜨면 확인하세요.

```powershell
flutter devices
```

`sdk gphone64 x86 64 (mobile) • emulator-5554 • android-x64` 가 보이면 준비된 것입니다.

> **에뮬레이터가 없는 PC 라면** 한 번만 만들면 됩니다.
> ```powershell
> flutter emulators --create --name lisn
> ```
> Android Studio 를 설치했는데 위 명령이 안 되면 Android Studio 의
> **Device Manager** 에서 만드세요. `sdkmanager`·`avdmanager` 는 `JAVA_HOME` 을
> 요구하는데, Flutter 는 Android Studio 의 JDK 를 스스로 찾으므로 **`flutter` 명령
> 쪽이 더 잘 됩니다.**

#### 그다음 원하는 화면으로 띄웁니다

**매번 로그인하지 않아도 됩니다.**

```powershell
C:\LISN\tools\show-screen.ps1 report
```

에뮬레이터가 꺼져 있으면 알아서 켜고 기다립니다. **절대 경로로 적었습니다** —
`.\tools\...` 는 저장소 루트에서만 되고, `frontend/app` 안에서 치면 못 찾습니다. 화면 목록은 인자 없이 실행하면 나옵니다.

직접 치려면 **앱 폴더로 들어가야 합니다.** 저장소 루트에서 `flutter run` 하면
`No pubspec.yaml file found` 가 납니다.

```powershell
cd frontend\app
flutter run --dart-define=DEV_LOGIN=force --dart-define=SCREEN=report
```

> `report`·`emergency` 는 평소에 **다른 화면 위에 얹혀 열리는 화면**이라, 부모 화면을
> 깔고 그 위에 띄웁니다. 그래야 **뒤로가기·닫기가 실제와 같게** 나옵니다.
>
> ⚠ **`force` 를 쓰세요.** `DEV_LOGIN=true` 는 **이미 로그인돼 있으면 건너뜁니다.**
> 앞서 손으로 다른 계정에 로그인해 뒀다면 그 계정 데이터가 그려지는데, 화면은
> 멀쩡해 보여서 **캡처를 뜬 뒤에야 압니다.** 실제로 한 번 겪었습니다.
> `force` 는 기존 세션을 버리고 데모 계정으로 다시 로그인합니다.

| `SCREEN` 키 | 화면 |
|---|---|
| `login` | `MAIN_LOGIN_01` |
| `reset` | `MAIN_LOGIN_02` |
| `join` | `MAIN_JOIN_01`~`03` |
| `home` | `MAIN_HOME_01` |
| `chat` | `MAIN_CHAT_01`·`02` |
| `lifelog` | `MAIN_LIFELOG_01` |
| `setting` | `MAIN_SETTING_01`·`02` (하단으로 스크롤) |
| `report` | `MAIN_REPORT_01` |
| `emergency` | `MAIN_EMERGENCY_01` |

**데이터까지 보이게 하려면** 백엔드가 떠 있고 데모 시드가 들어가 있어야 합니다.

```powershell
.\tools\start-dev.ps1
```

```powershell
$env:PGCLIENTENCODING = 'UTF8'
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres -d lisn -f db\seed_demo_persona.sql
```

> ⚠ **인증을 우회하는 플래그입니다.** 컴파일 시점 플래그라 평소 빌드에는 영향이 없고
> 릴리스 빌드에서는 무시되지만, **제출·시연 빌드에 이 플래그를 주지 마세요.**
> 자세한 내용은 `frontend/app/lib/dev_screens.dart` 상단 주석.

### 3. 관리자 웹 — 브라우저에서 바로

```powershell
.\tools\start-dev.ps1
```

`http://localhost:5173` 에서 **`role='ADMIN'` 인 계정**으로 로그인합니다.

> ⚠ `admin@lisn.dev` 는 **저장소에 없습니다.** 당시 PM PC 의 로컬 DB 에만 있던
> 계정입니다. 각자 회원가입한 계정을 승격해서 쓰세요 →
> [`docs/SETUP.md`](../SETUP.md) 14번.

> **5173 포트여야 합니다.** 백엔드 CORS 가 그 주소만 허용해서, 이전 vite 가 5173 을
> 잡고 있으면 5174 로 뜨고 요청이 전부 막힙니다.

## 캡처를 뜰 때

- **앱은 390×844** 기준입니다(시안 캔버스와 같음)
- 에뮬레이터 화면 캡처는 `Ctrl+S`, 또는 명령으로

  ```powershell
  adb exec-out screencap -p > report.png
  ```

  `adb` 는 `%LOCALAPPDATA%\Android\Sdk\platform-tools` 에 있습니다
- 관리자 웹은 **1280×800**

시안과 실제 화면이 다르면 **시안 쪽을 고치는 게 맞습니다.** 화면설계서는 설계 문서라
구현 이전의 의도를 담아야 하고, 구현이 시안을 따라간 것이지 그 반대가 아닙니다.
