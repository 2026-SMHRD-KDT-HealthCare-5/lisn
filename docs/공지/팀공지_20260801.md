## 2) 긴 버전 — 배경까지 설명해야 할 때

```
[귀기울임 개발 공지 8/1]

오늘 백엔드/AI 쪽 정리한 내용 공유합니다.

1. AI 추론 서버가 생겼습니다 (ai/server)
백엔드가 이미 호출하고 있었는데 받는 쪽이 없어서 파이프라인 검증이 안 됐습니다.
지금은 규칙 기반 임시 판정이라, 라이프로그 넣으면 홈 화면까지 값이 흐르는 걸
확인할 수 있습니다.
모델(LSTM AE + LightGBM)은 _predict() 함수 하나만 바꾸면 됩니다.
※ 지금 나오는 숫자는 모델 결과가 아닙니다. 발표 자료에 성능으로 쓰면 안 됩니다.

2. 챗봇 LLM을 개발 중에는 Gemini로 씁니다
OpenAI가 유료라 개발하면서 계속 쓰기 부담됩니다.
Gemini는 무료 한도가 있어서 개발용으로 씁니다.
설정 한 줄(LLM_PROVIDER)만 바꾸면 OpenAI로 돌아갑니다.
=> Gemini는 임시 수단이라 산출 문서는 안 고칩니다. 문서는 OpenAI가 정본이고,
   시연과 정확도 검사는 OpenAI로 합니다.

위기 탐지 정확도 확인했습니다.
- "배고파 죽겠다 진짜" -> 위기 아님 (오탐 안 남)
- "요즘 너무 지치고 아무것도 하기 싫어" -> 위기 아님
- "다 정리했어. 내일이면 끝이야" -> 위기 (HIGH)
응답 속도도 2.19초로 요구사항(3초) 안에 들어옵니다.

3. 범위에서 뺀 것 두 개
- 챗봇 음성 입력(STT) : 텍스트로 다 되고, 남은 일정에서 우선순위가 낮습니다.
  화면에 마이크 버튼 있으면 지우거나 "확장 예정"으로 표기해주세요.
  눌리는데 동작 안 하면 시연 때 바로 보입니다.
- PDF 내보내기 서버 API : 앱에서 만드는 걸로 바꿨습니다.
  앱에 리포트 화면이 이미 있어서 그대로 쓰면 되고,
  서버에서 만들려면 한글 폰트랑 차트 라이브러리를 새로 붙여야 합니다.

4. 화면설계서 이름 통일
메뉴 구성도 루트는 "귀기울임(LISN)"으로 갑니다. "마음이"는 앱 안 캐릭터 이름으로만.
"감정 변화 기록"은 "정서 리포트"로 통일합니다.
같은 화면인데 이름이 둘이면 메뉴에서 다른 기능처럼 보입니다.

5. 각자 해주실 것
- git pull
- backend/.env.example 를 .env 로 복사 후 DATABASE_URL, JWT_SECRET,
  ENCRYPTION_KEY 채우기
- ENCRYPTION_KEY 생성 :
  python -c "import base64,os; print(base64.b64encode(os.urandom(32)).decode())"
- LLM 키는 제가 개인적으로 보내드립니다. 단톡방에 올리지 마세요.

문서 쪽은 이번 건으로 추가 수정 없습니다.
화면설계서 디자인 작업(신규 6장, 콜아웃 재배치)만 남았습니다.
```
