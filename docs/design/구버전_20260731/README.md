# ⚠ 옛 시안 — 쓰지 마세요 (2026.07.31 이전)

**여기 있는 것은 참고용 기록입니다.** 현재 시안은 한 단계 위
[`docs/design/`](../) 에 화면 ID 이름으로 있습니다.

| | |
|---|---|
| **지금 쓰는 것** | `docs/design/MAIN_HOME_01.png` 등 화면 ID 이름 15장 |
| 여기 있는 것 | 그 전에 만든 홈 화면 시안 2장 |

## 왜 남겨두나

버린 게 아니라 **어디까지 바뀌었는지 대조할 수 있게** 둡니다. 홈 화면은
이후에 크게 바뀌었습니다 — 감정 이름 노출 제거(`SD-A⑤`), 히어로 위계 정리,
동작하지 않던 알림 종 제거.

## 왜 여기로 옮겼나

원래 `frontend/design/` 에 따로 있었습니다. 시안이 두 곳에 흩어져 있으면
**어느 쪽이 최신인지 알 수 없습니다.** `frontend/README.md` 스스로도
「앱이 실제로 쓰는 리소스가 아닙니다」라고 적어두고 있었습니다.

시안 정본은 `docs/design/` 하나입니다. 만드는 방법은
[`docs/design/README.md`](../README.md) 에 있습니다.
