## 5. 확정된 결정 — 문서에는 아직 미반영일 수 있음

이 내용들은 팀 논의에서 확정됐지만 산출물 문서에는 반영이 진행 중입니다.

- **안건 2** — iOS / Apple Health 구현 제외. 단 `platform_type` enum 의 `APPLE_HEALTH` 값은 유지합니다. 제거하면 컬럼에 값이 하나뿐이라 존재 이유가 사라집니다. 근거는 "Health Connect 가 Android 전용 API"라는 기술적 제약으로 서술.
- **안건 3** — 위기 탐지는 KcBERT 파인튜닝이 아니라 **키워드 규칙 + OpenAI 프롬프트 2단계**. 1차 키워드 필터는 백엔드 내부에 두어 API 장애 시에도 단독 동작.
- **안건 4** — 전 컬럼 AES-256 이 아니라 **위험도 기반 계층적 보호**. 라이프로그 측정치는 기간별 집계·복합 인덱스가 서비스 핵심 동작이라 컬럼 암호화 대상에서 제외.
- **안건 1-1** — 미확정.
