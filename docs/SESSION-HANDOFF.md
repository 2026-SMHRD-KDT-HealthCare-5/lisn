## 5. 이 문서들을 유지하는 방법

대화에서 결정된 내용은 **반드시 저장소에 남기세요.** 채팅 기록은 기기와 세션을 넘어가지 않지만 저장소는 따라갑니다.

- 결정이 나면 → [`작업이력.md`](review/작업이력.md) 맨 위에 기록하고, **해당 항목을 안건·체크리스트에서 삭제**
- 문서 개정을 반영하면 → 체크리스트에서 해당 항목 삭제
- 프로젝트 상태가 바뀌면 → 이 문서 3절
- 작업 규칙이나 새로 발견한 함정 → `CLAUDE.md`
