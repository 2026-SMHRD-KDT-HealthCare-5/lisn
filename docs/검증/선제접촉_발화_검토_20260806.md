## 먼저 볼 것 — 말투가 갈립니다

```
FRIEND      반말 3건 / 존댓말 3건      ← 부를 때마다 바뀝니다
COUNSELOR   존댓말 6건                 ✅
```

**서버가 직접 쓰는 고정 문구 6개는 전부 존댓말입니다.**

| | FRIEND | COUNSELOR |
|---|---|---|
| 세션 시작 인사말 | 존댓말 | 존댓말 |
| 선제 접촉 대체 발화 | 존댓말 | 존댓말 |
| 대화 실패 대체 발화 | 존댓말 | 존댓말 |

그런데 `PERSONA_PROMPTS["FRIEND"]` 는 **반말로 쓰여 있고 예시도 반말**입니다
— 「많이 힘들었겠다」 「그런 마음이 드는 게 자연스러워」. 모델이 그쪽으로
기울다가 문맥에 따라 존댓말로 돌아옵니다.

**사용자에게는 이렇게 보입니다.**

```
세션 시작   "안녕하세요. 오늘 하루는 어떠셨어요?"          존댓말
선제 접촉   "…마음이가 살짝 안부 물으러 왔어."            반말
```

같은 챗봇인데 말투가 다릅니다. 선제 접촉은 **쿨다운 3일마다 한 번** 오므로
매번 다른 사람이 말을 거는 것처럼 읽힙니다.

> ⚠ **선제 접촉만의 문제가 아닙니다.** `PERSONA_PROMPTS` 는 일반 대화
> (`analyze_and_reply`)도 같이 씁니다.

## 기계로는 안 잡히는 것 — 읽어주세요

- **문장 틀이 거의 같습니다.** 12건 중 대부분이 「최근 며칠 ~것 같아요.
  괜찮다면 ~들려주세요, 지금은 그냥 넘어가도 괜찮아요」입니다. 3일마다 거의
  같은 문장을 받으면 **자동 발송으로 읽히고**, 그러면 「누가 신경 써준다」는
  효과가 사라집니다.
- **`—`(em dash)가 COUNSELOR 에 세 번** 나옵니다. 채팅 말풍선에서 어색합니다.
- **지속일수를 말할지 방침이 없습니다.** 14일 사례에서 COUNSELOR 만 「최근
  2주 동안」이라고 기간을 말합니다. 프롬프트는 「수치를 그대로 읽어주지
  말고」라고 했는데 **지속일수도 수치**입니다.

## 기계 검사는 12건 전부 통과했습니다

두 문장 이내 · 진단명 없음 · 상태 단정 없음 · 내부 지표 용어 없음 · 수치
없음 · 따옴표 없음. **`_FEATURE_PHRASE` 치환이 실제로 동작합니다** —
「수면효율」이 「잠이 얕고」로, 「입면지연」이 「잠드는 데 걸리는 시간」으로
나갔습니다.
