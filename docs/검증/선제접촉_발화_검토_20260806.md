## 오늘 고친 것 — 말투를 존댓말로 통일했습니다

```
전   FRIEND  반말 3 / 존댓말 3      ← 부를 때마다 바뀜
후   FRIEND  존댓말 6 ✅ · COUNSELOR 존댓말 6 ✅
```

**서버 고정 문구 6개는 원래 전부 존댓말**이었는데
`PERSONA_PROMPTS["FRIEND"]` 만 반말로 쓰여 있었습니다(「많이 힘들었겠다」).
모델이 그 사이를 오갔습니다.

```
세션 시작   "안녕하세요. 오늘 하루는 어떠셨어요?"      존댓말
선제 접촉   "…마음이가 살짝 안부 물으러 왔어."        반말      ← 같은 챗봇
```

두 페르소나 프롬프트에 존댓말을 명시했습니다(PM 결정 · 2026.08.06).
**성격이 다른 것이지 거리가 다른 것이 아닙니다.**

⚠ 되돌리려면 `GREETING`·`FALLBACK_OUTREACH`·`FALLBACK_REPLY` 도 함께 —
한 곳만 고치면 다시 갈립니다.

## ⭐ 남은 것 둘 — 검토가 필요합니다

### 1. 페르소나가 거의 구분되지 않습니다

```
같은 사례에서 두 발화 유사도   평균 0.76
가장 비슷한 사례 「활동 저하」   0.97      ← 사실상 같은 문장
```

**첫 발화는 원래 구분이 약합니다** — 사용자가 아직 말을 안 했으니
COUNSELOR 가 「상황을 정리」할 재료가 없습니다. 그래도 화면설계서
`MAIN_CHAT_01` 이 두 성격을 **고르게** 하고 있으므로, 고른 결과가 같으면
고르게 한 의미가 없습니다.

> 말투를 통일하면서 **더 비슷해졌을 가능성**이 있습니다. 전에는 FRIEND 가
> 반말이라 그것만으로 구분됐습니다. **구분을 말투로 하고 있었다면 그건
> 원래 잘못된 구분**입니다 — 성격이 아니라 거리로 나눈 것이니까요.

### 2. 닫는 문장이 굳어 있습니다

```
서로 다른 표현   6종 / 12건
가장 잦은 것     4회 「괜찮으시면 요즘 어떻게 지내시는지 편하게 들려주세요.」
```

10/12 가 「괜찮으시면 요즘 어떻게 지내시는지…」 계열입니다.
**쿨다운 3일마다 오므로 같은 문장이 반복됩니다.** 자동 발송으로 읽히면
「누가 신경 써준다」는 효과가 사라집니다 — 선제 접촉의 존재 이유가
거기에 있습니다.
