# ⚠ 설계 의도로 답하는 것

**문헌값이 아닙니다.** 「왜 하필 그 숫자냐」가 아니라 **「왜 그런 장치를
두었냐」**로 답합니다.

## 선제 접촉 — 연속 3일 · 쿨다운 3일 · 09~21시

```
STREAK_DAYS_REQUIRED = 3     연속 이탈 며칠이면 말을 거나
COOLDOWN_DAYS = 3            한 번 걸면 며칠 쉬나
ACTIVE_FROM/TO = 09:00~21:00 언제 보내나
```

> **이 숫자들은 임상 근거가 아니라 빈도 상한입니다.** 하루 이틀 흔들리는
> 것은 누구나 있으니 **지속**을 봤고, 지속되는 동안 매일 보내면 앱을 닫게
> 되니 쿨다운을 뒀고, 새벽에 말을 거는 것은 그 자체가 해가 되니 시간대를
> 막았습니다. **값을 조정할 수 있게 상수로 빼두었습니다.**

⛔ **「3일이 임상적으로 유의미한 기간」이라고 말하지 마세요.** 근거가
없습니다.

## 기준선 14일 · 최소 3일

```
BASELINE_DAYS = 14           개인 기준선을 며칠로 잡나
MIN_DAYS_FOR_BASELINE = 3    최소 며칠 있어야 판정하나
```

> 14일은 **주간 리듬을 두 번 포함**합니다. 평일·주말 패턴이 한 번만
> 들어가면 그 주가 통째로 기준이 됩니다. 3일 미만이면 **422 로 끊습니다** —
> 편차 0 을 「정상」으로 적재하면 관제 대시보드에서 위험을 놓칩니다.

**이 「데이터가 없으면 정상이라고 하지 않는다」가 방어 포인트입니다.**
없는 것과 괜찮은 것을 구분한다는 뜻이니까요.

## 이탈 판정 z 2.0 · 지표 2개 이상

```
DEVIATION_Z = 2.0            이 값을 넘으면 「이탈」
MIN_DEVIANT_FEATURES = 2     그런 지표가 몇 개여야 「이탈한 날」
```

> **중앙값·MAD 기반 robust z** 입니다. 평균·표준편차를 쓰면 이상치 하나가
> 기준선 자체를 끌고 가서, 정작 이상한 날이 정상으로 보입니다.
> 2.0 은 이상치 판정에 흔히 쓰는 관례값이고, **지표 하나만으로 판정하지
> 않게** 2개 이상을 요구합니다.

⛔ 「2.0 은 선행연구값」이라고 하지 마세요. **관례**입니다.

## 대화 맥락 글자수

REPLY_CONTEXT_CHARS = 2000 · CRISIS_CONTEXT_CHARS = 600 · MAX_MESSAGE_CHARS = 500

# ⛔ 답이 약한 것 — 미리 알고 계세요

## ⭐ 감정 코드 매핑 — 가장 위험합니다

```python
if anomaly >= 0.5:    emotion_code = "SADNESS"
elif anomaly >= 0.25: emotion_code = "ANXIETY"
else:                 emotion_code = "HAPPINESS"
```

**이탈 정도를 3개 코드로 옮기는 규칙일 뿐입니다.** 0.5·0.25 에 근거가
없고, 무엇보다 **이것은 감정 분류가 아닙니다.** 코드 주석도 그렇게 적어
두었습니다.

> ⛔ **「감정을 분석·분류한다」고 말하지 마세요.** 과제명이 「감정 분석」
> 이라 입에 붙기 쉬운데, 여기서 질문이 들어오면 방어할 수 없습니다.

**이렇게 말합니다.**

> 감정 라벨이 붙은 국내 라이프로그 데이터셋을 확보하지 못해 **분류 모델을
> 학습하지 않기로 했습니다**(GLOBEM ROC-AUC 0.528 · LifeSnaps
> 0.479~0.540 실측). 대신 **개인 기준선 이탈 탐지**로 방향을 바꿨고,
> 감정 코드는 이탈 정도를 표시하는 **규칙 기반 산출값**입니다.
> `model_version` 이 `rule-` 로 시작하는 것이 그 표시입니다.

**빅데이터분석정의서가 이 내용을 이미 기록**하고 있습니다 — 「검증했고
채택하지 않았다」는 근거 문서입니다. 발표에서 그쪽을 가리키면 됩니다.

## `emotion_score = anomaly × 120` (100 상한)

왜 120 인지 설명할 근거가 없습니다. 이탈이 만점에 못 미쳐도 점수가 차게
하려는 조정값입니다.

> 물으면 **「표시용 척도이고 임계 판정에는 쓰지 않는다」**로 답합니다.
> 실제로 위험 단계는 `risk_level_of()` 가 감정 카테고리로 정합니다.

## `FULL_SCALE_Z = 4.0` · 상위 3개 평균

`anomaly` 를 0~1 로 정규화하는 분모, 그리고 7지표 중 상위 3개만 평균내는
선택입니다. 상위 3개는 **희석 방지**라는 이유가 있지만(일곱을 평균내면
두 지표가 크게 벗어나도 나머지 다섯에 묻힙니다), **4.0 에는 근거가
없습니다.**

# 정리 — 발표 원칙 셋

1. **「모델이 학습했다」고 하지 않습니다.** `rule-` 접두사가 그 약속입니다
2. **못 미친 것은 그대로 말합니다.** 재현율은 8/12 에 0.946 으로 목표를
   넘겼지만, **남은 미탐 6건은 완곡·신변 정리 유형**이고 문장 하나로는
   사람도 갈립니다(κ 0.388). 그 한계와 대응(`PL-29` 확인 질문)을 함께
   제시합니다. **응답 지연도 한때 예산을 938ms 넘겼다가 고친 것**이라,
   물으면 과정을 그대로 말합니다
3. **임의값은 「조정 가능한 정책」으로 말합니다.** 상수로 빼두었고 한
   곳에서만 바꾸면 된다는 것이 설계상의 답입니다

> **「할 수 있는데 안 했다」가 「몰라서 안 했다」보다 낫습니다.** 이 문서는
> 그 차이를 만드는 데 씁니다.
