> calories    → 단위: kcal

> hrv         → 단위: ms, 미측정 구간은 NULL
> ```
> `heart_rate`·`hrv` 의 **`미측정 구간은 NULL`** 은 `DEFAULT 0` 제거(`05-H`)의 근거이므로 특히 유지해야 합니다.

**8개 테이블 비고에서 `PK UUID,` 만 지우세요.** 그러면 각 테이블의 고유 특성이 눈에 띕니다.
