## ✅ 2. 체성분 기록이 화면에 없습니다 — `MAIN_LIFELOG_01` ❺ (2026.08.02 해결)

```
❺ 체성분 기록: 체중·체지방·근육량·기초대사량 측정 이력
```

**어느 화면에서도 그리지 않습니다.** `BodyComposition` 모델을 쓰는 화면이
하나도 없습니다.

- 서버 `GET /body-composition` **있음** (`backend/app/api/v1/lifelog.py:131`)
- 앱 `LifelogService.fetchBodyComposition()` **있음**
- **호출하는 화면이 없음** ← 여기만 비어 있습니다

`MAIN_JOIN_03`·`MAIN_SETTING_01` 이 체성분 수집 동의를 받고 있는데, 받은
데이터를 볼 곳이 없는 상태입니다.

**✅ 해결** — 라이프로그 화면 맨 아래에 「체성분 기록」 절을 붙였습니다.
체중·체지방·근육량·기초대사량 네 지표와 최근 5건의 측정 이력을 보여줍니다.

> ⚠ **위 목록과 따로 불러옵니다.** 체성분은 **선택 동의**라 없는 사용자가
> 많고, 여기서 실패하거나 비었다고 활동량·수면까지 사라지면 안 됩니다.
> 비어 있음은 **오류가 아니라 안내**로 그립니다 — 동의하지 않았거나
> 체성분계가 없으면 평생 비어 있는 게 정상입니다.

`test/body_composition_test.dart` 7건. 「조회 실패해도 활동량·수면은 남는다」와
「값이 없으면 0 이 아니라 –」를 함께 고정합니다. 에뮬레이터에서 빈 상태를
화면으로 확인했습니다.

## ✅ 4. `MAIN_SETTING_02` 가 독립 화면이 아닙니다 (2026.08.02 해결)

문서는 `MAIN_SETTING_01` ❸ 이 **「계정 관리·회원 탈퇴 화면(MAIN_SETTING_02)
이동」** 이라고 규정합니다. 실제로는 설정 화면 「기타」 절 안에 탈퇴 버튼만
있습니다.

| 문서 `MAIN_SETTING_02` | 앱 |
|---|---|
| ❶ 계정 정보: 이메일, 이름, **가입일** | 이메일·이름만 (프로필 카드) · **가입일 없음** |
| ❷ 비밀번호 변경 | **없음** (위 3번) |
| ❸ 회원 탈퇴 | 있음 (설정 화면 안) |
| ❹ 삭제 범위 안내 | 있음 |
| ❺ 최종 확인 후 `MAIN_LOGIN_01` 복귀 | 있음 |

**✅ 해결** — `lib/screens/account_screen.dart` 를 새로 만들고 설정 ❸ 에서
push 로 열도록 했습니다. 탈퇴 로직도 설정 화면에서 옮겼습니다.

| 항목 | 처리 |
|---|---|
| ❶ 가입일 | **`USERS` 에 `created_at` 이 없습니다.** 약관 동의 시각을 씁니다 — 약관 동의 없이는 가입이 성립하지 않고(`chk_terms_logic`) 가입 처리에서 같은 `now` 로 기록됩니다. 표시용 한 칸 때문에 스키마를 고치면 04·05 문서까지 따라옵니다 |
| ❷ 비밀번호 변경 | `changePassword()` 신설. 서버 `PATCH /users/me/password` 연결 |
| ❸❺ 탈퇴 | 설정 화면에서 이동 |
| ❹ 삭제 범위 | 팝업 **전에도** 화면에 상시 노출 |

`test/account_screen_test.dart` 11건. 에뮬레이터에서 화면으로도 확인했습니다.

> ⚠ 옮기는 과정에서 **컨트롤러 수명 버그**를 찾았습니다. `showDialog` 가
> 끝나자마자 `TextEditingController` 를 dispose 하는데, 그 시점에 다이얼로그는
> **아직 닫히는 중**이라 `TextField` 가 죽은 컨트롤러를 읽습니다
> (`A TextEditingController was used after being disposed`).
> **원래 설정 화면 탈퇴 코드에 있던 문제**이고 테스트가 없어 드러나지
> 않았습니다. 릴리스 빌드는 assert 가 빠져 조용히 넘어갑니다.

## ✅ 5. 정서 리포트에 「직접 지정」 기간이 없습니다 — `MAIN_REPORT_01` ❶ (2026.08.02 해결)

```
❶ 조회 기간: 주·월·직접 지정 전환. 변경 시 재조회
```

앱은 `week('주간', 7)` · `month('월간', 30)` **둘뿐**입니다
(`report_screen.dart:36-37`). 「직접 지정」이 없습니다.

> 서버 `GET /reports` 는 `from`·`to` 를 받으므로 **화면만 붙이면 됩니다.**

**✅ 해결** — 날짜 범위 선택기를 붙였습니다. 고른 뒤에는 세그먼트 라벨이
`7.26 ~ 8.02` 로 바뀌어 어느 구간을 보고 있는지 드러납니다.

> ⚠ **끝나는 날을 그날 끝까지** 잡습니다. 그대로 보내면 자정 기준이라
> 고른 마지막 날이 통째로 빠집니다.
>
> ⚠ **달력을 취소하면 기간을 바꾸지 않습니다.** 먼저 `custom` 으로 바꿔놓고
> 달력을 띄우면 취소했을 때 구간이 없는 상태로 남아 화면이 빕니다.
>
> ⚠ 날짜 선택기는 `MaterialLocalizations` 를 요구합니다. 앱에 한국어
> 델리게이트가 **아예 없어서** 그냥 넣었으면 여는 순간 죽었습니다
> (`flutter_localizations` 추가).

`test/report_custom_range_test.dart` 5건. 에뮬레이터에서 달력·재조회를
화면으로 확인했습니다.
