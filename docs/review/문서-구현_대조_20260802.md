## ⚠⚠ 4. `MAIN_SETTING_02` 가 독립 화면이 아닙니다

문서는 `MAIN_SETTING_01` ❸ 이 **「계정 관리·회원 탈퇴 화면(MAIN_SETTING_02)
이동」** 이라고 규정합니다. 실제로는 설정 화면 「기타」 절 안에 탈퇴 버튼만
있습니다.

| 문서 `MAIN_SETTING_02` | 앱 |
|---|---|
| ❶ 계정 정보: 이메일, 이름, **가입일** | 이메일·이름만 (프로필 카드) · **가입일 없음** |
| ❷ 비밀번호 변경 | **없음** (위 3번) |
| ❸ 회원 탈퇴 | 있음 (설정 화면 안) |
| ❹ 삭제 범위 안내 | 있음 |
| ❺ 최종 확인 후 `MAIN_LOGIN_01` 복귀 | 있음 |

**화면이 하나 통째로 빠진 셈입니다.** 슬라이드는 만들어져 있으니(18번),
심사에서 「설계는 있는데 구현이 없다」로 걸릴 수 있습니다.

## 처리 순서 제안

1. **1번(성격 이름)** — 문구 2곳. 가장 싸고 문서 3종과 어긋나 있어 우선
2. **4번 + 3번(`MAIN_SETTING_02`)** — 화면 하나를 만들면 둘이 같이 해결됩니다
3. **2번(체성분)** — 서비스·서버가 다 있어 화면만 붙이면 됩니다
4. **5번(직접 지정)** — 날짜 선택기 추가
5. **6번(음성 입력)** — 문서 쪽 문안 교체. `SD-A⑦` 로 체크리스트에 올릴 것

> 1·5 는 각각 한 시간 안쪽, 2·3·4 는 화면 작업이 있습니다.
