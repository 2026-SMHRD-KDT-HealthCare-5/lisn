## ⚠ 슬라이드 추가는 스크립트로 못 합니다

`tools/patch-pptx-text.ps1` 은 **텍스트 교체 전용**입니다. 슬라이드를 새로 넣으려면
slide XML · rels · `presentation.xml` · `[Content_Types].xml` **네 곳에 등록**해야 하고
이건 미검증입니다. **PowerPoint 에서 직접 추가하세요.**

> 다시 저장하면 **임베드 폰트가 풀릴 수 있습니다**(5.99MB → 305KB, 폰트 6개 → 0개로
> 실제 발생). 저장 전에 `파일 → 옵션 → 저장 → 파일에 글꼴 포함` 을 확인하세요.

기존 슬라이드의 **문안만** 바꾸는 것은 스크립트가 안전합니다(서식을 안 건드려 폰트가
풀리지 않음).

## 화면을 직접 보면서 작업하려면

세 가지 방법이 있고, 목적에 따라 다릅니다.

### 1. 시안만 보면 될 때 — 브라우저 (가장 빠름)

에뮬레이터도 서버도 필요 없습니다. **화면설계서에 들어갈 그림은 이 시안입니다.**

```powershell
start docs\design\MAIN_REPORT_01.png
```

원본 HTML 을 열면 확대해도 안 깨집니다.

```powershell
start docs\design\src\MAIN_REPORT_01.html
```

### 2. 실제 앱 화면을 볼 때 — 원하는 화면으로 바로 띄우기

Android 에뮬레이터가 필요합니다. **매번 로그인하지 않아도 됩니다.**

```powershell
cd frontend\app
flutter run --dart-define=DEV_LOGIN=true --dart-define=SCREEN=report
```

| `SCREEN` 키 | 화면 |
|---|---|
| `login` | `MAIN_LOGIN_01` |
| `reset` | `MAIN_LOGIN_02` |
| `join` | `MAIN_JOIN_01`~`03` |
| `home` | `MAIN_HOME_01` |
| `chat` | `MAIN_CHAT_01`·`02` |
| `lifelog` | `MAIN_LIFELOG_01` |
| `setting` | `MAIN_SETTING_01`·`02` (하단으로 스크롤) |
| `report` | `MAIN_REPORT_01` |
| `emergency` | `MAIN_EMERGENCY_01` |

**데이터까지 보이게 하려면** 백엔드가 떠 있고 데모 시드가 들어가 있어야 합니다.

```powershell
.\tools\start-dev.ps1
```

```powershell
psql -U postgres -d lisn -f db\seed_demo_persona.sql
```

> ⚠ **인증을 우회하는 플래그입니다.** 컴파일 시점 플래그라 평소 빌드에는 영향이 없고
> 릴리스 빌드에서는 무시되지만, **제출·시연 빌드에 이 플래그를 주지 마세요.**
> 자세한 내용은 `frontend/app/lib/dev_screens.dart` 상단 주석.

### 3. 관리자 웹 — 브라우저에서 바로

```powershell
.\tools\start-dev.ps1
```

`http://localhost:5173` 에서 `admin@lisn.dev` 로 로그인합니다.

> **5173 포트여야 합니다.** 백엔드 CORS 가 그 주소만 허용해서, 이전 vite 가 5173 을
> 잡고 있으면 5174 로 뜨고 요청이 전부 막힙니다.

## 캡처를 뜰 때

- **앱은 390×844** 기준입니다(시안 캔버스와 같음)
- 에뮬레이터 화면 캡처는 `Ctrl+S` 또는 `flutter screenshot`
- 관리자 웹은 **1280×800**

시안과 실제 화면이 다르면 **시안 쪽을 고치는 게 맞습니다.** 화면설계서는 설계 문서라
구현 이전의 의도를 담아야 하고, 구현이 시안을 따라간 것이지 그 반대가 아닙니다.
