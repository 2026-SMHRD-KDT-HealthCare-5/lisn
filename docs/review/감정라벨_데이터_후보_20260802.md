## 후보 정리

찾아보니 두 갈래인데, **우리 문제와 맞는 쪽은 하나뿐**입니다.

### ❌ 실험실 단기 자극형 — 문제가 다릅니다

| 데이터 | 내용 | 왜 안 맞나 |
|---|---|---|
| WESAD | 15명, 흉부+손목, baseline/stress/amusement | **10분 단위 유도 감정.** 우리는 14일 히스토리로 하루를 판정 |
| K-EmoCon | 16세션 10분 대화, EEG+웨어러블, 연속 감정 | 대화 중 순간 감정. 일상 라이프로그가 아님 |
| AMIGOS · DEAP | 영상 자극 + EEG/ECG, valence/arousal | EEG 는 우리 수집 경로에 없음 |

**공통 문제** — 이들은 「자극을 주고 그 순간의 반응」을 잽니다. 우리 시나리오는
「평소 대비 오늘의 수면·활동 편차」입니다. 피처도 시간 스케일도 다릅니다.

### ✅ LifeSnaps — 우리 문제와 같은 모양입니다

| 항목 | 내용 |
|---|---|
| 규모 | **71명 · 4개월** (현재 40명 → **1.8배**) |
| 기기 | **Fitbit Sense** — 수면 단계·걸음·심박·**HRV**·호흡수·체온 |
| 라벨 | **EMA 이산 감정** — happy / rested·relaxed / tense·anxious / tired / alert / sad / neutral |
| 추가 라벨 | PANAS(긍·부정 정서), S-STAI(불안) |
| 접근 | **Zenodo 즉시 다운로드, 승인 불필요** (615MB) |
| 라이선스 | **CC-BY 4.0** — 출처만 밝히면 사용·재배포 가능 |

**PhysioNet 45일 심사와 달리 오늘 바로 받을 수 있습니다.**

## 우리 감정 9종과 얼마나 맞나

| 우리 `EMOTIONS` | LifeSnaps EMA | 대응 |
|---|---|---|
| `HAPPINESS` 행복 | happy | ✅ |
| `JOY` 기쁨 · `DELIGHT` 즐거움 | — | ⚠ happy 하나에서 셋을 못 가릅니다 |
| `SADNESS` 슬픔 | sad | ✅ |
| `ANXIETY` 불안 | tense/anxious | ✅ |
| `LONELINESS` 외로움 | — | ❌ 없음 |
| `ANGER` 분노 | — | ❌ 없음 |
| `DESPAIR` 절망 · `CRISIS` 위기 | — | ❌ 없음 (대화 쪽 위기 탐지가 담당) |

**9종 그대로는 못 맞춥니다.** 실제로 대응되는 것은 **4종**
(행복·슬픔·불안 + 중립/이완)입니다.

> 「기쁨·즐거움·행복」을 걸음 수와 수면으로 가를 수 있다고 보는 것 자체가
> 무리한 설계였을 수 있습니다. **생체 데이터가 잡는 것은 각성도와 정서가(價)
> 이지 감정 이름이 아닙니다** — 이건 정서 컴퓨팅 쪽의 일반적 한계입니다.

## 그래서 선택지는 셋입니다

### A. LifeSnaps 로 4종 분류 — 현실적

- 71명, 즉시 다운로드, HRV 까지 있어 **현재 피처보다 넓습니다**
- 9종 → **4종으로 줄여** 문서를 개정
- ⚠ 남은 26일에 전처리·학습·검증을 넣어야 합니다. **되는지 안 되는지도 모릅니다**

### B. 지금 상태 유지 — 안전

- 「설계는 9종, 구현은 규칙 3종, 이유는 라벨 부재」로 발표
- **이미 근거가 탄탄합니다** — 0.528 재현 확인, 라벨 부재 확인
- 새 데이터로 시도했다가 또 0.5 가 나오면 시간만 씁니다

### C. LifeSnaps 로 **검증만** — 절충

- 학습해서 넣지 않고, **「다른 데이터로도 안 되더라」를 확인**만 합니다
- 71명으로도 안 되면 「40명이라 안 된 게 아니다」가 되어 **결론이 더 강해집니다**
- 되면? 그때 넣을지 판단합니다

## ✅ 실제로 돌려봤습니다 (2026.08.02)

**C(검증만) 를 실행했습니다.** LifeSnaps 를 받아 우리 파이프라인과 같은
조건으로 맞췄습니다 — 14일 히스토리 집계, 「평소 대비 편차」 피처,
참가자 단위 분할(`GroupKFold`), 참가자를 섞어 20회 반복.

`ai/train/eval_lifesnaps.py` · **63명 · 2290일 · 피처 65개**

| 감정 | 양성률 | 평균 AUC | 95% 구간 | 0.5 이하 |
|---|---|---|---|---|
| HAPPY | 27.4% | **0.540** | 0.525 ~ 0.556 | 0/20 |
| TIRED | 38.4% | **0.533** | 0.512 ~ 0.551 | 0/20 |
| NEUTRAL | 26.3% | 0.527 | 0.496 ~ 0.554 | 3/20 |
| RESTED/RELAXED | 38.9% | 0.518 | 0.493 ~ 0.544 | 2/20 |
| TENSE/ANXIOUS | 22.0% | 0.497 | 0.471 ~ 0.514 | 11/20 |
| SAD | 5.5% | 0.485 | 0.457 ~ 0.517 | 15/20 |
| ALERT | 13.3% | 0.479 | 0.435 ~ 0.512 | 16/20 |

### 결론 — 기존 판단이 맞았습니다

**참가자를 40명 → 63명으로, 피처를 8개 → 65개로 늘려도 같습니다.**
GLOBEM 에서 0.528 이었던 것이 LifeSnaps 에서 0.479~0.540 입니다.

- **`SAD`·`TENSE/ANXIOUS` 가 0.5 언저리** — 우리가 정작 잡아야 하는 감정입니다.
  슬픔은 양성률이 5.5% 라 표본도 적습니다
- 0.5 를 넘긴 둘(`HAPPY` 0.540 · `TIRED` 0.533)도 **실용적인 수준이 아닙니다.**
  0.54 는 「동전보다 아주 조금 나음」이지 분류기라고 부를 수 없습니다
- `TIRED` 가 그나마 나온 것은 당연합니다 — **수면 시간과 직접 이어진 감정**이라
  거의 동어반복입니다. 「어제 못 잤으니 피곤하다」를 맞힌 것이지 정서 추정이 아닙니다

> **「40명이 적어서 그런 것 아니냐」는 반문이 사라졌습니다.** 다른 데이터,
> 더 많은 참가자, 더 많은 피처, 감정 라벨 직접 사용 — 그래도 같습니다.

### 그래서 무엇이 달라지나

- 모델을 **채택하지 않습니다.** 규칙 판정 유지가 맞습니다
- 발표에서 **「40명이라서」가 아니라 「생체 신호로 감정 이름을 가르는 것 자체가
  안 된다」** 로 말할 수 있게 됐습니다. 근거가 두 데이터셋입니다
- 걸음·수면이 잡는 것은 **각성도(피곤/각성)** 쪽이고, **정서가(슬픔/불안)** 는
  거의 못 잡는다는 패턴이 표에 그대로 보입니다
