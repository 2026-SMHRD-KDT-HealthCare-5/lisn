## SD-15. slide15 `MAIN_SETTING_01` — 화면설명 전면 교체 ⭐⭐

> ❷ 연동 관리 버튼: OS 헬스 플랫폼 권한 설정 화면으로 연결. 권한 변경이 필요한 경우 안내 문구 노출
> ❸ 알림 설정: 맞춤 케어 알림 수신 여부 토글. 해제 시 콘텐츠 추천 푸시가 발송되지 않음

**교체 — 화면개요**

> MLCM_200

> ❺ 체성분은 `BODY_COMPOSITION_METRICS` 로 별도 테이블이며 `measured_at` 기준입니다. 15분 주기로 쌓이는 `LIFELOG_METRICS` 와 주기가 달라 **차트에서 구분해야** 합니다.

> ❻ 은 `DEVICE_HEALTH_CONNECTIONS.last_synced_at` 을 사용합니다. `NFR-DV-002` 의 미수신 감지 요건에 대응하는 화면 요소입니다.

## SD-10. slide10 `MAIN_JOIN_03` — 화면설명 전면 교체 ⭐⭐

**화면개요는 "웨어러블 기기를 연동할 수 있는 페이지" 인데 화면설명은 `MAIN_JOIN_02` 복사본입니다.** 연동 관련 설명이 한 줄도 없습니다.

**교체 — 화면설명**
> ❶ 가입 완료 안내: 계정 생성이 완료되었음을 알리는 메시지
> ❷ 수집 항목 안내: 필수(활동량 - 걸음 수·이동 거리·소모 칼로리, 수면 패턴 - 수면 단계별 시간)와 선택(체성분 - 체중·골격근량 등)을 구분해 표시
> ❸ 항목별 동의 체크박스: 필수·선택 항목에 대해 개별 동의를 받음
> ❹ 연동하기 버튼: OS 헬스 플랫폼(Health Connect) 권한 요청 창을 호출. 승인 결과에 따라 연동 상태를 저장
> ❺ 건너뛰기: 연동 없이 홈 화면(MAIN_HOME_01)으로 이동. 이후 설정(MAIN_SETTING_01)에서 연동 가능
> ❻ (예외) 권한 승인을 거부하거나 취소한 경우 서비스 이용에 제한이 있을 수 있다는 경고 팝업을 노출하고 재시도 버튼을 제공

**교체 — 화면이름**
> 웨어러블 연동 설정 화면

**교체 — 화면개요**
> 회원가입 완료 후 스마트워치·체성분계 데이터 수집 항목에 동의하고 OS 헬스 플랫폼 연동 권한을 설정하는 화면

**교체 — 관련 유스케이스 ID**
> MLCM_110

**교체 — 메뉴경로**
> 로그인/약관동의/회원가입 정보 입력/웨어러블 연동

> ❺ 를 넣는 이유는 `MLCM_110` 의 선행조건이 "회원가입 및 로그인을 완료하여 메인/초기 설정 화면에 진입한 상태" 이고, **연동을 나중에 할 수 있어야** 마이페이지 재진입 분기가 성립하기 때문입니다.
>
> Android 전용이므로 화면 문구에 "OS 헬스 플랫폼" 대신 **Health Connect** 를 직접 써도 됩니다.

## SD-12. slide12 `MAIN_CHAT_02` — 대화 기록 기능 복원 ⭐

**화면개요에는 "대화 기록 조회/삭제 가능" 이라 되어 있고 메뉴 구성도에도 「대화 기록 / 상세보기 / 삭제」가 있는데, 화면설명에서만 빠졌습니다.**

> ❽ (예외) 외부 API 오류로 응답 생성에 실패한 경우 페르소나 톤에 맞춘 대체 응답을 노출
